# Material javaDEBUG

Biblioteca Java e Android para inspeção visual e depuração de interfaces.

📖 Sobre o projeto

O Material javaDEBUG é uma biblioteca em desenvolvimento destinada a auxiliar desenvolvedores na inspeção e depuração de componentes de interface em aplicativos Android.

O projeto pretende facilitar a identificação dos limites, dimensões, coordenadas, margens, preenchimentos internos (padding) e áreas clicáveis dos componentes.

🚧 Estado do projeto

Status: Em desenvolvimento.

Os recursos descritos neste documento representam os objetivos planejados. A disponibilidade de cada funcionalidade dependerá da implementação.

✨ Recursos planejados

- Inspeção visual de componentes.
- Marcação dos limites dos elementos da interface.
- Exibição de largura, altura e coordenadas.
- Inspeção de margens, padding e áreas clicáveis.
- Visualização da hierarquia dos componentes.
- Personalização das cores e dos contornos.
- Modos de inspeção simples, detalhado e avançado.
- Exportação e importação de configurações de depuração.
- Suporte ao formato de arquivo ".debug".

📦 Formatos planejados

Formato| Finalidade
".jar"| Biblioteca Java.
".aar"| Biblioteca Android com recursos específicos da plataforma.
".debug"| Formato próprio para configurações e dados de depuração.
